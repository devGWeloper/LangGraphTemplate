# 환경 구축 가이드

**설치는 파일 두 개 더블클릭이면 끝납니다.** 아래 3단계만 하시면 됩니다.
막히면 뒤쪽 [자주 겪는 오류](#자주-겪는-오류)를 보시고, 그래도 안 되면 화면을 캡처해서 리드에게 보내주세요.

> 🖥️ Windows 기준입니다. 명령어를 직접 칠 일이 있으면 **명령 프롬프트(cmd)** 를 쓰세요.
> 시작 메뉴에서 `cmd` 를 검색하면 나옵니다.

---

## 1단계 — `setup.bat` 더블클릭

프로젝트 폴더 안의 **`setup.bat`** 을 더블클릭하세요.

검은 창이 뜨고 아래처럼 진행됩니다. **3~5분** 걸립니다.

```
[1/5] 파이썬 확인 중...
      파이썬 3.11.9 확인
[2/5] Node.js 확인 중...
      Node.js v20.11.0 확인
[3/5] 파이썬 패키지 설치 중... (2~3분, 화면이 멈춘 것처럼 보여도 기다려주세요)
      완료
[4/5] 접속 정보 파일(.env) 준비 중...
      .env 파일을 만들었습니다.
[5/5] 화면 빌드 중... (1~2분)
      완료

============================================================
  설치가 끝났습니다
============================================================
```

**`[실패]` 가 뜨면** 창에 해결 방법이 같이 나옵니다. 그대로 따라 하시면 됩니다.

> 파이썬이나 Node.js 가 없다는 안내가 나오면, 안내대로 설치한 뒤
> **창을 닫고 `setup.bat` 을 다시 더블클릭**하세요.

---

## 2단계 — `.env` 파일에 값 채우기

`setup.bat` 이 끝나면 **`.env` 파일이 메모장으로 자동으로 열립니다.**
아래 세 줄에 값을 채우고 저장(`Ctrl + S`)한 뒤 창을 닫으세요.

```
LLM_BASE_URL=여기에_주소를_붙여넣으세요
LLM_API_KEY=여기에_키를_붙여넣으세요
LLM_MODEL=여기에_모델_이름을_적으세요
PORT=8021
```

값은 **리드에게 받으시면 됩니다.**

### `.env` 파일은 어디에 있나요?

**프로젝트 최상위 폴더**입니다. `run.py`, `requirements.txt`, `setup.bat` 과 **같은 자리**입니다.

```
LangGraphTemplate\
├─ .env              ← 여기! (setup.bat 이 만들어 줍니다)
├─ .env.example
├─ setup.bat
├─ start.bat
├─ run.py
├─ requirements.txt
├─ app\
├─ frontend\
└─ teams\
   └─ team3\         ← 여기 아닙니다
```

> ⚠️ **`teams\team3\` 안이나 `app\` 안에 넣으면 안 됩니다.** 서버가 찾지 못합니다.

### 직접 만들어야 한다면

`setup.bat` 이 자동으로 만들어주므로 보통은 직접 만들 일이 없습니다.
혹시 지워졌다면 **cmd 에서** 아래를 실행하세요.

```cmd
copy .env.example .env
notepad .env
```

> ⚠️ **메모장에서 "새로 만들기 → 저장"으로 만들지 마세요.**
> 윈도우가 확장자를 숨기기 때문에 `.env.txt` 라는 엉뚱한 파일이 만들어집니다.
> 겉으로는 `.env` 로 보여서 원인을 찾기가 아주 어렵습니다. 꼭 위의 `copy` 명령을 쓰세요.
>
> 제대로 만들어졌는지는 cmd 에서 `dir .env*` 로 확인할 수 있습니다.
> `.env` 만 나오면 정상이고, `.env.txt` 가 같이 나오면 잘못된 것입니다.

## 3단계 — `start.bat` 더블클릭

**`start.bat`** 을 더블클릭하면 서버가 켜지고, 잠시 후 브라우저가 자동으로 열립니다.

```
============================================================
  제조AX서비스1팀 AI 챌린지
============================================================

  주소 : http://localhost:8021

  잠시 후 브라우저가 자동으로 열립니다.
  서버를 끄려면 이 창에서 Ctrl + C 를 누르세요.
```

브라우저가 안 열리면 직접 **http://localhost:8021** 로 들어가세요.

탭이 8개(0조 ~ 7조) 보이면 성공입니다.

- **0조 탭** — 여행지 추천 예제가 바로 동작합니다. 먼저 여기서 대화해보세요.
- **우리 조 탭** — 아직 "개발 중" 상태입니다. 이제 `teams\teamN\workflow.py` 를 채우면 됩니다.

**서버를 끄려면** 검은 창에서 `Ctrl + C` 를 누르거나 창을 닫으면 됩니다.

> 💡 코드를 고치고 저장하면 서버가 알아서 다시 뜹니다.
> 브라우저는 새로고침(F5)만 하시면 됩니다.

---

## 개발할 때 — 화면 없이 빠르게 돌려보기

서버를 켜고 브라우저를 오가는 것보다, 파일 하나만 실행해보는 게 빠릅니다.
cmd 에서 프로젝트 폴더로 이동한 뒤:

```cmd
.venv\Scripts\python.exe teams\team3\workflow.py "테스트할 질문"
```

노드가 하나씩 실행되면서 **각 노드가 만든 값**이 출력됩니다.
어느 노드에서 값이 이상해지는지 바로 보입니다.

## 제출 전 자가 점검

```cmd
.venv\Scripts\python.exe scripts\selfcheck.py team3
```

`[통과] 제출 준비가 되었습니다.` 가 나오면 커밋하시면 됩니다.

## 자주 겪는 오류

### `setup.bat` 을 더블클릭했는데 창이 깜빡하고 사라져요

폴더 경로에 문제가 있을 가능성이 큽니다. 프로젝트 폴더를 `C:\work\LangGraphTemplate` 처럼
**짧고 한글·공백이 없는 경로**로 옮긴 뒤 다시 시도해보세요.

원인을 보고 싶으면 cmd 를 열고 그 폴더로 이동한 뒤 `setup.bat` 을 쳐서 실행하세요. 메시지가 남습니다.

### `[실패] 파이썬을 찾을 수 없습니다`

파이썬이 설치되지 않았거나, 설치할 때 **"Add python.exe to PATH"** 를 체크하지 않은 경우입니다.
[python.org/downloads](https://www.python.org/downloads/) 에서 3.11 이상을 받아 설치하되,
**설치 첫 화면 맨 아래 체크박스를 반드시 켜세요.** 이미 설치했다면 설치 파일을 다시 실행해
"Modify" 로 고칠 수 있습니다.

설치 후에는 **창을 닫았다가 다시 열어야** 인식됩니다.

### `[실패] Node.js 를 찾을 수 없습니다`

[nodejs.org](https://nodejs.org/) 에서 LTS 버전을 받아 설치한 뒤,
창을 닫고 `setup.bat` 을 다시 실행하세요.

### 화면에 "LLM 접속 정보가 설정되지 않았습니다" 가 떠요

`.env` 파일의 값 세 개가 비어 있습니다. 2단계를 다시 확인하세요.
값을 채운 뒤에는 **서버를 껐다가 다시 켜야** 반영됩니다.

`.env` 를 분명히 채웠는데도 같은 메시지가 나온다면, 파일 이름이 `.env.txt` 로 잘못 만들어졌을 수 있습니다.
cmd 에서 `dir .env*` 로 확인해보세요.

### `ModuleNotFoundError: No module named 'app'`

프로젝트 최상위 폴더가 아닌 곳에서 실행했습니다.
`start.bat` 을 쓰면 이 문제가 생기지 않습니다.
직접 실행 중이었다면 `cd` 로 `LangGraphTemplate` 폴더까지 이동한 뒤 다시 실행하세요.
지금 어느 폴더인지는 cmd 에서 `cd` 만 쳐보면 나옵니다.

### 포트 8021 이 이미 사용 중이라고 나와요

이전에 켜둔 서버가 아직 살아 있습니다. 그 검은 창을 찾아 `Ctrl + C` 로 끄세요.
찾을 수 없다면 `.env` 의 `PORT` 를 `8022` 로 바꾸고 `start.bat` 을 다시 실행하세요.
(이때 접속 주소도 http://localhost:8022 로 바뀝니다)

## 부록 — 직접 설치하기

`setup.bat` 이 하는 일을 손으로 하고 싶을 때만 보시면 됩니다.
cmd 에서 프로젝트 폴더로 이동한 뒤:

```cmd
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
cd frontend
npm install
npm run build
cd ..
python run.py
```

`.venv\Scripts\activate` 를 실행하면 프롬프트 앞에 `(.venv)` 가 붙습니다.
**창을 새로 열 때마다 다시 실행해야 합니다.**

활성화가 번거로우면 `python` 대신 `.venv\Scripts\python.exe` 를 쓰시면 됩니다.
